# Simulation media

Add a screenshot or short exported animation from your own MATLAB run before sharing the repository on LinkedIn.

Recommended filenames: `snake_robot_animation.png` and `snake_robot_demo.mp4`.

Note: `.mp4` is ignored by default in `.gitignore`. To deliberately add one, run `git add -f media/snake_robot_demo.mp4` or host the video on LinkedIn and link it from the README. Do not commit very large videos to Git.
