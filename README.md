🐍⚙️ Project 03 | Bio-Inspired Snake Robot — Modelling and Locomotion Simulation Using MATLAB

After working on 6-DOF robotic manipulators, I wanted to explore a different challenge in robotics: how multiple interconnected joints can coordinate to produce snake-like movement.

I developed a modular snake robot simulation in MATLAB, combining 3D forward kinematics, travelling-wave gait generation and a simplified physics-based locomotion model.

🔹 Project Highlights

✅ 12 rigid links and 11 alternating yaw/pitch revolute joints
✅ 3D forward kinematic modelling and visualization
✅ Sinusoidal travelling-wave gait generation
✅ Anisotropic resistive-force model for planar locomotion
✅ Computed body translation and heading rather than a predefined global trajectory
✅ MATLAB animation, motion plots and MP4 export

One of the most interesting lessons was understanding the difference between kinematic animation and physically generated locomotion.

The current simulation uses a reduced-order planar friction model alongside 3D articulated visualization. My next objective is to extend it toward full multibody dynamics with ground contact, actuator torques and obstacle navigation.

💻 Tools: MATLAB | Robot Kinematics | Numerical Modelling | 3D Visualization
